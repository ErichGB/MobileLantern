# MobileLantern Web

[![Deploy Hugo site to Pages](https://github.com/ErichGB/MobileLantern/actions/workflows/hugo.yml/badge.svg)](https://github.com/ErichGB/MobileLantern/actions/workflows/hugo.yml)

Sitio web oficial para **MobileLantern**, el sistema de orquestación de clase con IA y ambient display para aprendizaje colaborativo.

🌐 **Sitio en vivo**: [https://erichgb.github.io/MobileLantern/](https://erichgb.github.io/MobileLantern/)

## 📋 Contenido

Este repositorio contiene el sitio web de MobileLantern, que incluye:

- **Homepage**: Presentación del sistema con características principales
- **Manual de usuario**: Guía completa para estudiantes
  - Comenzar (Getting Started)
  - ¿Qué es MobileLantern?
  - Instalación de la aplicación
  - Uso básico
  - Preguntas frecuentes (FAQ)
- **Generador de códigos QR**: Herramienta para profesores para generar códigos de check-in
- **Descarga de APK**: Información y enlaces para descargar la aplicación móvil

## 🛠️ Stack Tecnológico

- **[Hugo](https://gohugo.io/)** (v0.104.0+): Generador de sitios estáticos
- **[Tailwind CSS](https://tailwindcss.com/)** (v4.x): Framework CSS utility-first
- **[Alpine.js](https://alpinejs.dev/)**: Framework JavaScript ligero
- **[QRCode.js](https://github.com/soldair/node-qrcode)**: Generación de códigos QR
- **GitHub Pages**: Hosting y deployment automático

## 🎨 Características

### Tema claro/oscuro

El sitio incluye un sistema de temas con tres modos:
- **Claro**: Diseño con fondo blanco
- **Oscuro**: Diseño con fondo slate-950
- **Automático**: Se adapta a la preferencia del sistema

Atajo de teclado: `Cmd/Ctrl + T` para cambiar entre temas.

### Generador de códigos QR

Herramienta interactiva que permite a los profesores:
- Configurar usuario y contraseña para grupos
- Definir el contexto pedagógico de la IA
- Generar códigos QR en tiempo real
- Descargar los códigos en formato PNG
- Contador de caracteres con validación

### Manual interactivo

Documentación completa con:
- Navegación mediante sidebar
- Tabla de contenidos (TOC) automática
- Navegación prev/next entre páginas
- Diseño responsive
- Búsqueda integrada
